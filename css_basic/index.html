Welcome to My Website

Hello and welcome! This is my very first webpage, built as part of the ALU Web Development curriculum. I'm learning the fundamentals of HTML, starting with structure, semantics, and validation.

About This Project

This project walks through building a simple, valid HTML page from scratch. It starts with the most basic skeleton possible and grows step by step into a small multi-page website with proper navigation.

Along the way, I'm learning why W3C validation matters: it ensures the markup is well-formed, accessible, and behaves consistently across different browsers and devices.

What You'll Find Here

On this site you'll find this homepage, along with a second page showcasing an embedded tweet. Feel free to click around and check out the tweets page as well!
