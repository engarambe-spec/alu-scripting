# Regular Expressions

Ruby scripts using regular expressions, each accepting a single
command-line argument and matching it against a specific pattern.

## Tasks

- `0-simply_match_school.rb` — matches the literal string `School`
  (all occurrences, concatenated)
- `1-repetition_token_0.rb` — matches `hb` + zero or more `t` + `n`
- `5-beginning_and_end.rb` — matches a string starting with `h`, ending
  with `n`, with exactly one character in between
- `6-phone_number.rb` — matches a 10-digit phone number with no separators
- `7-OMG_WHY_ARE_YOU_SHOUTING.rb` — extracts and concatenates every
  capital letter in a string
- `8-textme.rb` — parses a TextMe SMS log line into `sender,receiver,flags`

## Usage

```bash
./0-simply_match_school.rb "Best School"
```
